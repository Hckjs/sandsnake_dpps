# MAGIC Resources

This directory contains reference performance data for the MAGIC telescopes.

## Provenance

The data were obtained from the MAGIC collaboration's [technical implementation and performance page](https://magic.mpp.mpg.de/newcomers/magic-team/technical-implementation0/).

The MAGIC performance data are also linked internally in the CTAO GitLab project [performance-other-instruments](https://gitlab.cta-observatory.org/cta-science/simulations/public-products/performance-other-instruments).
