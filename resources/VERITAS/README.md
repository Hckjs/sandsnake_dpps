# VERITAS Resources

This directory contains reference performance data for VERITAS.

## Provenance

The data were obtained from the official [VERITAS specifications page](https://veritas.sao.arizona.edu/about-veritas/veritas-specifications).

The performance results were also published in [*Performance of the VERITAS experiment* (Proceedings of the 34th International Cosmic Ray Conference, 2015)](https://ui.adsabs.harvard.edu/abs/2015ICRC...34..771P/abstract).

The VERITAS performance data are additionally linked internally in the CTAO GitLab project [performance-other-instruments](https://gitlab.cta-observatory.org/cta-science/simulations/public-products/performance-other-instruments).
