# CTAO Resources

This directory collects reference performance data for the Cherenkov Telescope Array Observatory (CTAO).

## Contents and provenance

### CTA requirements

The files in [`CTA_Requirements/`](CTA_Requirements/) contain CTA performance requirements obtained from the Zenodo record [*CTA Performance requirements*](https://zenodo.org/records/5163273).

### PROD5 instrument response functions

CTAO prod5 instrument response functions (IRFs) placed in this directory originate from the Zenodo record [*CTA prod5 instrument response functions*](https://zenodo.org/records/5499840) processed with EventDisplay.
